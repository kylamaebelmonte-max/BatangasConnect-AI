# BatangasConnect AI (Phase 1 — Android)

A smart mobile tourism guide for Batangas Province built natively in Kotlin and Jetpack Compose.

## Features
- *Authentication:* Secure user registration, login, and session logout connected to a real cloud backend.
- *Explore Dashboard:* Swipeable Featured Spots carousel (Taal Basilica, Taal Volcano, Laiya Beach, San Sebastian Cathedral), full destination album modal, category filters (Beaches, Heritage, Food & Cafe, Diving, Culture), and real-time search.
- *Interactive Batangas Map:* Custom Jetpack Compose Canvas vector map plotting Taal Lake, Volcano Island, and clickable municipal pins.
- *AI Tourism Guide:* Conversational travel assistant providing instant recommendations for places, local delicacies, and activities.

## Technology Stack
- *Language:* Kotlin
- *UI Framework:* Jetpack Compose (Material 3)
- *IDE & SDK:* Android Studio, Android SDK
- *Backend & Cloud Services:* Cloud Authentication Backend, ElevenLabs TTS API (ElevenLabsService.kt)

## How to Run
1. Clone this repository: git clone https://github.com/kylamaebelmonte-max/BatangasConnect-AI.git
2. Open the folder in *Android Studio*, sync Gradle, and run on a physical Android device (API 26+), or install BatangasConnectAI_Phase1.apk.
